# AI 生圖冒險島｜手機、平板離線版

台灣校園人工智慧教育協會的離線提示詞與圖片體驗。選擇角色、畫風與場景，探索 256 種預先製作的冒險圖片。此版本不需要帳號或 AI API；圖片、音樂與操作程式可下載到裝置。

## 場景圖片預覽

場景卡提供不含主角的局部圖片預覽。256 組預覽逐一對應角色、畫風與場景，直接顯示最終圖片內經檢視的背景區域，因此預覽與揭曉具有相同的場景及畫風。部分原圖有景深效果，預覽保留原有樣貌。

`scene-previews.js` 記錄每張圖片的裁切座標；若更換最終圖片，必須重新檢視並更新相應座標，不能沿用其他角色或畫風的範圍。

## 安裝與離線使用

1. 首次安裝請連上網路，開啟本專案的 GitHub Pages 發布網址。
2. iPhone／iPad：使用 Safari 的「分享」→「加入主畫面」。Android：使用 Chrome 的「安裝到主畫面」或瀏覽器選單中的安裝選項。
3. 從主畫面圖示重新開啟「生圖冒險島」，按首頁的「下載離線內容」。完整素材約 127 MB，建議使用 Wi-Fi。
4. 下載期間保持畫面開啟；中途暫停或失敗後，可再次按下載接續。只有所有檔案驗證完成才會顯示「可離線使用」。
5. 按「重新開啟」，再開啟飛航模式，關閉並重新開啟 App，檢查角色、圖片與音樂。

按「開始體驗」會開始背景音樂；回到首頁會暫停。既有音量與音效偏好會保留，0% 音量仍保持靜音。

安裝與下載是兩個步驟。特別是 iPhone／iPad，請從主畫面圖示開啟後再下載。清除網站資料、移除 App 或系統回收網站儲存空間後，可能需要重新下載。

## 電腦使用

將完整 ZIP 解壓縮，保留所有檔案與 `assets` 資料夾，再開啟 `index.html`。本機檔案模式可直接體驗；手機安裝與下載功能需由 HTTPS 網址開啟。

## 網站部署與更新

這是無建置步驟的靜態網站，可放在 HTTPS 網站根目錄或子資料夾。GitHub Pages 使用目前發布分支的根目錄；保留 `.nojekyll`，避免檔案被額外轉換。

每次變更 HTML、CSS、程式、圖示或素材後，先重新生成下載清單：

```sh
node tools/build-offline-manifest.cjs .
node tools/build-offline-manifest.cjs . --verify
```

一次提交完整檔案與新的 `offline-manifest.json`。不要在主機上修改、壓縮改寫或注入 HTML／JS 內容，因為下載時會比對每個檔案的原始長度與 SHA-256。傳输層 gzip／Brotli 不受影響。`.gitattributes` 會保留每個檔案的精確位元組，避免換行轉換讓驗證失敗。

使用者按「檢查並更新離線內容」後，完整新版本下載成功才會切換；下載失敗時仍保留原有完整版本。更新成功後請按「重新開啟」。

## 驗證範圍

已以程式測試下載進度、續傳、SHA-256 與長度驗證、取消、儲存空間不足、子路徑、原子版本更新、舊頁版本保留及音訊 Range 回應。安裝及實際裝置儲存、音訊播放仍需依上方步驟在目標 iPhone／iPad／Android 實機驗收。

素材的來源及第三方圖示授權說明隨 `assets` 保留。本專案未額外授予圖片或角色的再授權。
